Установка на Synology NAS

Пошаговая инструкция для DSM 7. Только графический интерфейс — терминал и SSH не понадобятся ни на одном шаге.

Synology DS223 · DSM 7 Web Station · PHP 8.2 · Apache 2.4 ≈ 25–35 минут Нужен файл: kurs-portal.zip

Что в архиве и что понадобится

Файл / папка в архивеЧто это
kurs/Весь портал: страницы входа, курса, тестов и кабинета; PHP-серверная часть; файлы уроков; банки вопросов. Эта папка целиком становится сайтом.
ИНСТРУКЦИЯ-УСТАНОВКА.htmlЭта инструкция (её копия после установки будет лежать внутри портала, в папке admin/).

Понадобятся:

  • Synology NAS с DSM 7 (проверено на DS223) и учётная запись администратора;
  • файл kurs-portal.zip на вашем компьютере;
  • браузер и адрес NAS (например, http://192.168.1.50:5000 — его видно в Панель управления → Сеть → Сетевой интерфейс, либо на finds.synology.com).
Почему без SSH это безопасно. База данных лежит в отдельной общей папке kurs-data — она не является частью сайта, скачать её по ссылке нельзя. Права на запись этой папке выдаются мышкой через File Station, а не командами.

1Пакеты: Web Station, PHP 8.2, Apache 2.4

Главное меню → Центр пакетов

Найдите и нажмите Установить для трёх пакетов (если они уже установлены — просто проверьте):

  • Web Station — веб-сервер DSM;
  • PHP 8.2 (или PHP 8.1) — язык портала;
  • Apache HTTP Server 2.4 — на нём работают защитные правила .htaccess из архива.
Не используйте PHP 7.3 / 7.4 / 8.0 — Synology прекратил их поддержку (август 2025), портал на них не заработает.

2Общая папка для базы данных

Панель управления → Общая папка → Создать → Создать
  • Имя: kurs-data (именно так, латиницей, через дефис);
  • Расположение: Volume 1;
  • Шифрование — «Без шифрования», корзину можно отключить;
  • остальные страницы мастера — без изменений, Далее до конца.

Здесь будут храниться аккаунты (пароли — в виде необратимых хэшей), прогресс учеников, результаты тестов и журнал. Папка находится вне сайта: у неё нет веб-адреса.

3Права на папку kurs-data — мышкой

File Station → правый клик на папке kurs-data → Свойства → вкладка Права → Создать
  • Пользователь или группа: everyone;
  • Права: отметьте Чтение и Запись;
  • отметьте «Применить к этой папке, подпапкам и файлам»;
  • Готово → Сохранить.

Это нужно, чтобы веб-сервер мог записывать базу данных. Папка не видна по HTTP, поэтому такие права не открывают её содержимое наружу.

Если строки «everyone» нет — выберите группу http (пользователь веб-сервера DSM) и так же отметьте Чтение + Запись. Смысл тот же.

4Загрузка и распаковка архива

File Station → папка web → Загрузка (или перетащите файл мышкой)
  1. Откройте в File Station общую папку web — её создал пакет Web Station.
  2. Загрузите туда файл kurs-portal.zip.
  3. Правый клик на архиве → Извлечь → Извлечь сюда.
  4. Появится папка web/kurs — это и есть портал. Проверьте, что внутри есть index.php, login.php, папки api, kursy, banks.
  5. Рядом распакуется ИНСТРУКЦИЯ-УСТАНОВКА.html — её можно оставить или удалить.
  6. Сам архив kurs-portal.zip после распаковки можно удалить (правый клик → Удалить).
Ничего переименовывать и перекладывать не нужно: в архиве папка уже называется kurs.

5Настройка PHP-профиля

Главное меню → Web Station → Настройки языка сценариев → профиль PHP 8.2 → Изменить
  1. Кнопка Расширения (Extensions): отметьте галочками и сохраните:
    • pdo_sqlite — работа с базой данных;
    • sqlite3 — та же база, запасной драйвер;
    • mbstring — корректная кириллица.
  2. Поле open_basedir:
    • если поле пустое — не трогайте;
    • если там что-то написано (например, /volume1/web:/tmp) — допишите в конец :/volume1/kurs-data, чтобы получилось /volume1/web:/tmp:/volume1/kurs-data. Иначе PHP не сможет открыть базу.

То же самое сделайте для профиля PHP 8.1, если решили использовать его.

6Создание веб-портала

Web Station → Веб-служба → Создать → Веб-портал → Портал на основе папки
  • Документ-корень: /web/kurs (кнопка обзора → папка web → kurs);
  • PHP: ваш профиль PHP 8.2;
  • Веб-сервер: Apache HTTP Server 2.4 — обязательно: защитные правила .htaccess работают только на Apache;
  • Имя: например, kurs;
  • Имя хоста: можно оставить пустым — DSM назначит порт и покажет его в списке служб (например, 8080). Адрес портала будет http://АДРЕС_NAS:8080. Если у вас есть домен/сертификат — укажите имя хоста здесь;
  • Далее → Готово.
Запишите адрес портала (IP и порт из Web Station) — он понадобится дальше и его вы дадите ученикам. Если DSM показал предупреждение про брандмауэр: Панель управления → Безопасность → Брандмауэр — разрешите этот порт (для школьной сети достаточно профиля «Разрешить» для локальных подсетей).

7Установка портала в браузере

Откройте: http://АДРЕС_NAS:ПОРТ/admin/install.php
  1. Таблица проверки окружения — все строки должны быть зелёными. В красной строке сразу написано, что нажать, чтобы исправить (все исправления — в GUI).
  2. Заполните форму:
    • фамилия и имя преподавателя;
    • логин (латиница, 3–24 символа);
    • пароль — не короче 8 символов;
    • первый класс (например, 10Б) и порог зачёта теста (по умолчанию 60 %).
  3. Нажмите Установить и создать преподавателя.
Пароль нельзя восстановить. Он сразу превращается в необратимый хэш (Argon2id, а если его нет в PHP — bcrypt) и в таком виде записывается в базу. Восстановить пароль по хэшу не может никто, включая администратора NAS. Запишите пароль в надёжном месте и не используйте пароль от почты.

Установщик сам создаст в папке kurs-data базу данных kurs.db и служебные файлы — вручную туда ничего копировать не нужно.

8Отключить установщик

File Station → web → kurs → admin → правый клик на install.php → Переименовать

Переименуйте install.php в install.php.off — страница установки перестанет отвечать. Если когда-нибудь понадобится переустановка (см. «Если что-то пошло не так»), переименуйте обратно.

9Проверка здоровья и безопасности — в браузере

Откройте по очереди три адреса (подставьте адрес своего портала):

АдресЧто должно быть
http://АДРЕС:ПОРТ/api/index.php?a=health Все проверки зелёные; банки вопросов: U1=32, U2=43, U3=36, U4=44
http://АДРЕС:ПОРТ/banks/u1.json 403 Forbidden (это банк с правильными ответами — он закрыт)
http://АДРЕС:ПОРТ/kursy/prepod.html 403 Forbidden (это версия курса с заметками преподавателя)

Затем войдите как преподаватель на странице входа и осмотрите кабинет: вкладки «Журнал», «Ученики», «Настройки» должны открываться.

База данных лежит в общей папке kurs-data вне сайта — веб-адреса у неё нет вообще, проверять её нечем и негде. Это правильная картина.

10HTTPS через обратный прокси (по желанию, но рекомендуется)

Если портал будет доступен из интернета, пароли нужно передавать только по HTTPS. У Synology это настраивается целиком в GUI:

  1. Панель управления → Безопасность → Сертификат — добавьте сертификат (например, Let's Encrypt через Добавить → Получить сертификат от Let's Encrypt).
  2. Панель управления → Портал входа → Дополнительно → Обратный прокси — создайте правило: источник https, ваш домен, 443 → назначение http, localhost, порт портала из шага 6.
  3. В этом же правиле: вкладка Пользовательские заголовки → Создать → Пользовательский заголовок: имя X-Forwarded-Proto, значение https.

Благодаря этому заголовку портал поймёт, что работает по HTTPS: поставит cookie пометку Secure, и строка «HTTPS» в a=health станет зелёной.

11Ученики и первый урок

Дайте ученикам адрес портала. На странице входа — вкладка Регистрация: фамилия и имя, логин, пароль, класс (класс создаётся автоматически при первой регистрации).

Регистрацию можно в любой момент отключить в кабинете: Кабинет → Настройки → «Разрешить самостоятельную регистрацию».

12Резервные копии и обновления

Резервные копии

Всё ценное (аккаунты, прогресс, оценки, аудит) лежит в одной общей папке kurs-data:

  • Панель управления → Hyper Backup — создайте задачу на папку kurs-data (и, по желанию, web/kurs); или
  • просто периодически копируйте папку kurs-data в другое место средствами File Station (правый клик → Копировать). Лучше делать это, когда порталом никто не пользуется.

Обновление портала

  1. Сделайте копию папки kurs-data.
  2. В File Station удалите папку web/kurs и распакуйте новый архив так же, как в шаге 4.
  3. Откройте api/index.php?a=health.

База данных при этом не трогается: все аккаунты и результаты останутся. Ученикам переустанавливать ничего не нужно.

Если что-то пошло не так

СимптомЧто сделать (только GUI)
При открытии портала — 500 Internal Server Error Откройте api/index.php?a=health — красная строка подскажет причину. Чаще всего: не включены расширения PHP (шаг 5) или мешает open_basedir.
«Каталог данных недоступен для записи» Повторите шаг 3: File Station → kurs-data → Свойства → Права → everyone → Чтение + Запись → применить ко всем вложенным.
В install.php красная строка «Каталог данных» Папка не создана (шаг 2) или создана с другим именем. Имя должно быть ровно kurs-data, том — Volume 1.
Страница отдаётся текстом / скачивается вместо выполнения Портал создан без PHP-профиля: Web Station → Веб-служба → изменить портал → выбрать PHP 8.2.
banks/u1.json или kursy/prepod.html открываются вместо 403 Портал работает не на Apache: Web Station → Веб-служба → изменить → веб-сервер Apache HTTP Server 2.4. На nginx правила .htaccess не действуют.
Прогресс не сохраняется Ученик должен войти под своей учёткой (без входа сохранение на сервер не работает). Проверьте строки health и что браузер не в приватном режиме.
Тест не открывается api/index.php?a=health: банки должны быть U1=32, U2=43, U3=36, U4=44. Если ✗ — архив распакован не полностью, повторите шаг 4.
CSV с оценками «кракозябрами» в Excel Не должно: выгрузка в UTF-8 с BOM и разделителем ;. Если у вас другой Excel — используйте выгрузку JSON.
Забыт пароль преподавателя Восстановить хэш нельзя. Крайний вариант (потеря всех данных): в File Station переименуйте файл kurs-data/kurs.db в kurs.db.old, верните имя install.php.off → install.php и пройдите шаг 7 заново — портал станет чистым. Поэтому заранее делайте резервные копии (шаг 12).
Портал не открывается у учеников, но открывается у вас Брандмауэр: Панель управления → Безопасность → Брандмауэр — разрешите порт портала (шаг 6).

Подробнее о каждой проверке — страница api/index.php?a=health: она сама диагностирует окружение и пишет, что нажать.
