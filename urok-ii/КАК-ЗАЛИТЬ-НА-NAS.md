# Как залить портал на DS223 и запустить — только через графический интерфейс

Полная пошаговая инструкция (красивая, для печати и для работы с экрана):
**`ИНСТРУКЦИЯ-УСТАНОВКА.html`** — она лежит в корне архива `dist/kurs-portal.zip`
и внутри портала в папке `admin/`. Ниже — краткая выжимка.

**SSH и командная строка не нужны ни на одном шаге.** Все действия выполняются
в браузере: Центр пакетов, Панель управления, File Station, Web Station.

Что берём с собой: **`dist/kurs-portal.zip`** — единственный архив. Внутри:

| Что | Куда попадает |
|---|---|
| `kurs/` | распаковывается в `/volume1/web/kurs` — это весь портал |
| `ИНСТРУКЦИЯ-УСТАНОВКА.html` | инструкция (остаётся рядом, можно удалить) |

Папку данных `kurs-data` создаёте вы сами в GUI (шаг 2), а служебные файлы в ней
(`.htaccess`, `README.md`, базу `kurs.db`) установщик создаст автоматически.

---

## Шаги (кратко)

**1. Пакеты.** Центр пакетов → установить **Web Station**, **PHP 8.2** (или 8.1),
**Apache HTTP Server 2.4**. PHP 7.3/7.4/8.0 сняты с поддержки Synology — не используйте их.

**2. Папка для базы.** Панель управления → Общая папка → Создать:
имя **`kurs-data`**, том Volume 1, без шифрования. Она вне сайта — базу нельзя скачать по ссылке.

**3. Права на папку (мышкой).** File Station → правый клик на `kurs-data` → Свойства →
Права → Создать: пользователь **`everyone`** (или группа `http`), права **Чтение + Запись**,
«Применить к этой папке, подпапкам и файлам» → Готово → Сохранить.

**4. Загрузка.** File Station → папка `web` → загрузить `kurs-portal.zip` →
правый клик на архиве → Извлечь → **«Извлечь сюда»**. Получится `/volume1/web/kurs`
(переименовывать ничего не нужно). Архив после этого можно удалить.

**5. PHP-профиль.** Web Station → Настройки языка сценариев → PHP 8.2 → Изменить:
- «Расширения»: включить **`pdo_sqlite`**, **`sqlite3`**, **`mbstring`**;
- `open_basedir`: если поле не пустое — дописать в конец **`:/volume1/kurs-data`**.

**6. Портал.** Web Station → Веб-служба → Создать → Веб-портал →
**Портал на основе папки**: документ-корень **`/web/kurs`**, PHP **8.2**,
веб-сервер **Apache HTTP Server 2.4** (на нём работают `.htaccess`-защиты).
Имя хоста можно оставить пустым — DSM назначит порт и покажет его в списке служб.
Адрес портала: `http://АДРЕС_NAS:ПОРТ`.

**7. Установка.** Открыть `http://АДРЕС_NAS:ПОРТ/admin/install.php`:
- верхняя таблица — проверка окружения, всё должно быть зелёным
  (в красной строке написано, что нажать);
- ниже задать **пароль преподавателя** (не короче 8 символов), фамилию и имя,
  первый класс, порог зачёта;
- нажать «Установить».

Пароль сразу превращается в хэш **Argon2id** (если его нет в профиле PHP — bcrypt)
и записывается в базу. Восстановить пароль по хэшу нельзя никому, включая
администратора NAS. Установщик сам создаст в `kurs-data` базу и служебные файлы.

**8. Закрыть установщик.** File Station → `web/kurs/admin` → правый клик на
`install.php` → **Переименовать** → `install.php.off`.

**9. Проверить (в браузере).**
- `http://АДРЕС:ПОРТ/api/index.php?a=health` — все пункты зелёные,
  банки `U1=32, U2=43, U3=36, U4=44`;
- `http://АДРЕС:ПОРТ/banks/u1.json` — должно быть **403** (банк с ответами закрыт);
- `http://АДРЕС:ПОРТ/kursy/prepod.html` — должно быть **403** (версия для преподавателя закрыта);
- база лежит в `kurs-data` вне сайта — веб-адреса у неё нет.

**10. HTTPS (по желанию).** Панель управления → Портал входа → Дополнительно →
Обратный прокси: правило `https://ваш-домен` → `http://localhost:ПОРТ`, и в нём
вкладка «Пользовательские заголовки» → Создать → заголовок **`X-Forwarded-Proto` = `https`**.
Тогда портал поставит cookie `Secure`, и пункт «HTTPS» в диагностике станет зелёным.

**11. Ученики.** Дать им адрес портала. На странице входа — вкладка **«Регистрация»**:
фамилия и имя, логин, пароль, класс. Класс создаётся автоматически при первой регистрации.

**12. Резервные копии.** Всё ценное — в общей папке `kurs-data`.
Hyper Backup на эту папку или периодическая копия средствами File Station.

## Первый урок: чек-лист

- [ ] ученик зарегистрировался и попал в оболочку курса;
- [ ] слева четыре урока, открыт только первый;
- [ ] слайды идут по порядку, чек-лист практики блокирует «Далее»;
- [ ] после сдачи теста урока 1 открылся урок 2;
- [ ] прогресс переживает закрытие вкладки и вход с другого компьютера;
- [ ] в кабинете видна попытка, CSV открывается в Excel с кириллицей;
- [ ] кнопка «Выйти» чистит локальный прогресс (за компьютер садится следующий).

## Если что-то не так

| Симптом | Куда смотреть (всё в GUI) |
|---|---|
| 500 Internal Server Error | `api/index.php?a=health`; обычно нет `pdo_sqlite` или мешает `open_basedir` (шаг 5) |
| «Каталог данных недоступен для записи» | повторить шаг 3: Свойства → Права → `everyone` → Чтение + Запись |
| Красная строка «Каталог данных» в install.php | папка не создана или называется не ровно `kurs-data` (шаг 2) |
| Страница скачивается вместо выполнения | портал создан без PHP: Web Station → Веб-служба → изменить → PHP 8.2 |
| `banks/u1.json` открывается вместо 403 | портал работает не на Apache: Web Station → изменить → Apache 2.4 |
| Прогресс не сохраняется | надпись под списком уроков слева; проверьте, что ученик вошёл (без входа мост не работает) |
| Тест не открывается | `a=health`: банки должны быть `U1=32, U2=43, U3=36, U4=44`; иначе распаковать архив заново (шаг 4) |
| Ученик видит заметки преподавателя | не сработал `.htaccess` — проверьте, что портал на Apache (шаг 6) и `kursy/prepod.html` даёт 403 (шаг 9) |
| CSV «кракозябрами» | не должно: выгрузка в UTF-8 с BOM и `;`; если Excel другой — берите JSON |
| Забыт пароль преподавателя | хэш не восстанавливается; крайний вариант — переименовать `kurs-data/kurs.db` в `.old` и пройти шаг 7 заново (портал станет чистым) |
| Ученики не видят портал, а вы видите | брандмауэр: Панель управления → Безопасность → Брандмауэр → разрешить порт портала |
